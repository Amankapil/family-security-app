# FAMILY SAFETY NETWORK — MASTER DEVELOPMENT PROMPT

You are a senior Android engineer, full-stack JavaScript engineer, backend architect, security engineer, DevOps engineer, UX designer, and product architect.

Build a PRIVATE FAMILY SAFETY NETWORK.

This is a real personal application that I will install on Android phones belonging to my trusted family members.

The application is designed to help family members know whether each other are safe during daily travel.

It is NOT a surveillance application.

Every person whose phone is registered must explicitly know that their location is being shared and must consent to it.

The first users will likely be:

- Father
- Mother
- Brother
- Sister
- Me

But DO NOT hardcode these people.

The system must support ANY number of authorized family members.

18. ADAPTIVE LOCATION FREQUENCY
==================================================

DO NOT track every few seconds all day.

HOME:

Use geofence and low-frequency updates.

WORK:

Use geofence and low-frequency updates.

TRAVELLING:

Approximately 30–60 second updates.

STATIONARY:

Reduce frequency where safe.

POSSIBLE INCIDENT:

Temporarily increase frequency if technically appropriate.

SOS:

Immediately request current location.

All intervals must be configurable.

Battery efficiency is a primary requirement.

24. FALSE POSITIVE REDUCTION
==================================================

GPS can fail.

Internet can fail.

Android can kill background services.

Phones can enter low-signal areas.

Family members can stop somewhere.

Routes can change.

Therefore:

Never create a critical alert from one weak signal.

Use multiple signals.

Example:

Location missing for 2 minutes:

No alert.

Location missing for 10+ minutes:

Check:

- Network
- Battery
- Last location
- Last speed
- Journey state
- Device state

Then potentially create:

WARNING
