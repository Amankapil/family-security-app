# Family Safety Android Client

Native Android application built in Kotlin.

## Key Modules to be configured in Phase 5:
- `com.familysafety.app.data`: Room Database for offline location buffering and Retrofit network client.
- `com.familysafety.app.service`: Foreground Location Service with persistent notification channel.
- `com.familysafety.app.ui`: Dynamic home view, Pairing QR scanner, One-touch "I'm OK", and 2-second press SOS safety action.
